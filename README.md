# 营销素材合规审核智能体 - 三通道并行裁决系统

> 基于多智能体协作架构的量化投资产品营销素材合规审核解决方案

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 项目概述

本项目构建了一个**三通道并行裁决**的合规审核系统，专门解决AI审核中"同素材重复测试输出不一致"的核心痛点。系统采用**严格版+标准版+宽松版**三个智能体并行审核，通过加权投票机制输出稳定、可追溯的最终结论。

**核心应用场景**：持牌证券投资咨询机构的营销素材合规预审，覆盖量化投资产品的推文、活动文案、客户反馈展示等场景。

### 三通道设计原理

| 版本 | 角色定位 | 豁免规则 | 判定门槛 |
|------|---------|---------|---------|
| **严格版** | 从严把关，不漏判 | 无豁免 | B级≥1即拒 |
| **标准版** | 基准线，对齐人工 | 7大豁免模式 | B级≥2即拒 |
| **宽松版** | 从宽处理，不错杀 | 放宽20% | B级≥3才拒 |

**加权投票机制**：标准版2票 + 严格版1票 + 宽松版1票

## 核心创新点

### 1. 豁免规则体系（解决AI误拒问题）

基于55条人工审核正面案例，构建7大豁免模式：

- **EX-001**: 客户反馈+标准风险提示
- **EX-002**: 策略容量数字（客观事实）
- **EX-003**: 树懒量化系统（券商系统名）
- **EX-004**: 概念描述（非正式命名）
- **EX-005**: 客户行为转变描述
- **EX-006**: 策略功能介绍+正确命名
- **EX-007**: 正常营销引导+无绩效结合

### 2. 判定依据固定模板（解决输出不稳定问题）

定义7类标准化判定句式，消除LLM自由文本的不稳定性：

```
全自动类："该表述暗示客户无需自主决策，违反投顾业务客户自主决策原则..."
产品称谓类："该表述将量化策略错误介绍为[称呼]，违反产品正确定义规则..."
收益类："该表述涉及收益承诺/夸大/诱导，违反不承诺收益底线..."
...
```

### 3. 合规规则矩阵

覆盖9大类合规规则：
- 五大核心底线（不承诺收益、不替代决策等）
- 产品正确定义（量化策略 vs 量化交易系统）
- 全自动/代客决策表述规则
- 回测数据展示规范
- 客户反馈展示标准
- 收益相关营销话术
- 开户相关规则
- 个股推荐与点位指导
- 投顾观点类素材规则

## 技术实现

### 部署平台
- **阿里云百炼**：三通道智能体实例 + 可视化工作流编排

### 模型配置
```yaml
temperature: 0        # 消除随机性
seed: 42              # 固定随机种子
top_p: 1              # 关闭随机采样
max_tokens: 2000
```

### 工作流节点
1. **开始节点** - 接收素材输入
2. **Python代码节点** - 规则预处理
3. **知识库节点** - 检索豁免规则
4. **条件分支** - 路由到三通道
5. **三个AI节点** - 并行审核（严格/标准/宽松）
6. **变量处理节点** - 聚合三通道输出
7. **内容整合节点** - 加权投票裁决
8. **结束节点** - 输出最终结论
